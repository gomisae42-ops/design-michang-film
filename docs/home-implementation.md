## 2. Hero 구현
- 첫 데스크톱 프레임 좌우 8% 인셋(영상 표시 폭 84%), 따뜻한 미색 배경. 선·그림자·둥근 모서리 없음.
- clip-path만 열리며 레이아웃 폭을 계속 계산하지 않는다. 900ms, 모바일 700ms. 스크롤 가로채기 없음.
- 네 LOCK COPY를 0.4/1.4/2.5/3.3초 순서로 표시. 최종 행이 가장 크고 굵다.
- 스크롤·휠·터치 이동·클릭·키보드 입력 즉시 모든 카피 표시 및 프레임 열림. 이후 위로 올라가도 다시 닫히지 않는다.
- 세션 중 HOME 재방문 시 열린 상태. sessionStorage 사용이 막혀도 페이지는 동작한다.
- A/B 무음 루프, playsInline, 정지/재생 버튼. 화면 밖·백그라운드에서 정지.
- prefers-reduced-motion, 데이터 절약 또는 2G 감지 시 영상 대신 실제 스틸. 모션 줄이기는 카피 전체와 열린 프레임 즉시 표시.
- JS가 없을 때도 서버 HTML에 모든 카피와 CTA, 실제 포스터가 존재한다.
- 모바일 9:16 전용 파일. CTA는 두 개의 독립 행으로 배치해 좁은 폭에서도 단어가 잘리지 않도록 했다.

## 4. 비워둔 영역
- Clip B의 정면 얼굴: 홈페이지 공개 권한 미확인으로 뒷모습·손·기계로 대체.
- 분야별 이미지: 다큐멘터리만 실제 이미지. 나머지 6개 분야는 텍스트만 유지.
- 실제 콘티·기획 문서·촬영 비하인드·편람 결과물: 미제공으로 임의 생성하지 않음.
- 검증되지 않은 납품 범위·성과 수치·인증·기관 로고는 노출하지 않음.
- TRUST의 1990년은 제공 설계서의 회사 연혁 사실만 사용. 영상사업 업력과 구별.

## 5. Desktop 확인
- 1024/1440px 및 태블릿 768px: 가로 넘침 없음, H1 한 개, 깨진 이미지 없음.
- 첫 프레임 inset(2% 8% 9%) 확인. 네 카피 어휘·순서 그대로 출력.
- A/B 전환, 수동 일시정지, 화면 밖 재생 중단 확인.
- 대표 프로젝트 앵커와 상담 링크 확인. 현재 페이지에서 상세 링크는 기존 /projects/gunpo/를 사용한다.
- 최종 소스로 새로 연 브라우저 탭의 콘솔 오류 없음. 개발 중 잠깐 발생했던 JSX 닫힘 오류는 수정 후 타입 검사·빌드 통과.

## 6. Mobile 확인
- 320/390px: 가로 넘침·과폭 제목·이미지 오류 없음.
- 모바일 전용 MP4 선택과 700ms 프레임 전환 확인.
- 첫 입력 이후 네 카피 opacity 1 확인. CTA를 두 행으로 정리.
- 실제 작업 스틸, 텍스트 서비스 목록, 세로 타임라인, 최종 CTA 확인.
- 최종 CTA가 보일 때 공통 하단 고정 상담 링크 숨김, /contact/ 실제 이동 확인.
- 데스크톱 브라우저의 모바일 viewport 검증이며, 실물 iOS/Android 기기 측정은 하지 않았다.

## 7. Performance
- 영상 A+B 합계: 데스크톱 1.80MB, 모바일 0.78MB. 나머지 실제 스틸은 WebP.
- 자동재생은 현재 장면만, B는 초기 표시 이후 준비. 영상이 늦거나 실패해도 포스터 유지.
- 스크롤 프레임별 JS 계산/외부 모션 라이브러리/새 패키지 추가 없음.
- TypeScript 및 Next.js 정적 프로덕션 빌드 통과.
- 실기기 저속 네트워크·Lighthouse·실사용 Core Web Vitals는 미측정. 특히 iOS 저전력 모드에서는 정지 화면이 표시될 수 있다.
